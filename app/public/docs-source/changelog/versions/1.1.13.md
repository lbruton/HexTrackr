# Version 1.1.13 - Dependency Security Refresh

**Release Status**: ✅ Released

Brought the dependency updates that only existed on `main` into `dev` and ran `npm audit fix`, so `dev` is the single source of truth. Production dependencies now report zero known vulnerabilities.

- Merged `main` into `dev`, including lint and review cleanups in several controllers and shared scripts.
- Version references updated across the app, README and compose file.
